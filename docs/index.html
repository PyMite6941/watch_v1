ESP32‑C3 SuperMini Watch (Watch V1)

A cyber‑punk style, see‑through wrist watch built around an ESP32‑C3 SuperMini, a 4‑digit 7‑segment display, two tactile buttons, ambient‑light sensor (LDR) for auto‑brightness, and a rechargeable Li‑Po battery charged via USB‑C.

Overview

This repository contains all source files, documentation, and 3D models needed to build, replicate, and modify the watch. The design is open‑source (MIT License) and intended as a gift for teachers and fellow makers.

Repository layout

docs/   – Documentation (README, build guide, license)
src/    – Source files: firmware, schematic, parts list, KiCad project
assets/ – 3D models (OpenSCAD) and other assets for the enclosure

Getting started

  1. Read the Build Guide for wiring and assembly instructions.
  2. Order the parts listed in parts_list.md.
  3. Wire the breadboard per ascii_schematic.txt.
  4. Flash the firmware (firmware.ino) to the ESP32‑C3 SuperMini.
  5. Test the display, buttons, and auto‑brightness.
  6. When satisfied, generate Gerbers from the KiCad project (watch_v1.kicad_proj) and order a PCB, or assemble on perfboard.
  7. Print the enclosure from the OpenSCAD files in assets/.
  8. Assemble the printed case, insert the PCB and battery, and seal with optional conformal coating.

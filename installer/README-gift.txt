WATCH STUDIO - the app for your watch
=====================================

Watch Studio sets up your watch, chooses which screens it shows, makes new
apps for it (step timers, random name pickers, countdowns, messages), records
its sensors and backs it all up. It works without the watch too: press
"Try the demo watch".

It is tiny (about 0.1 MB) and is removed like any other program.


WINDOWS 10 / 11
---------------
1. Unzip this folder (right-click the zip > Extract All).
2. Double-click Setup.cmd.
   If Windows says "Windows protected your PC": More info > Run anyway.
   (It is home-made, so it is not signed. It needs no administrator rights.)
3. Follow the installer: Next > Next > Install > Finish.

Open it:   type "watch" in the Start menu, or press Ctrl + Alt + W.
Remove it: Settings > Apps > Installed apps > Watch Studio > Uninstall.


MAC
---
1. Unzip this folder (double-click the zip).
2. Right-click (or Control-click) "Setup Watch Studio.command" > Open > Open.
   (Double-clicking works from the second time on. macOS asks the first time
   because the file is home-made and not signed.)
3. Answer the few questions.

Open it:   Cmd + Space, type "watch", Return. Or Launchpad, or the Dock.
Remove it: drag Watch Studio from Applications to the Bin.


GOOD TO KNOW
------------
- The window is drawn by Microsoft Edge or Google Chrome, which is how it can
  talk to the watch over USB and Bluetooth while staying so small. Edge is
  already part of Windows. On a Mac, install Chrome or Edge if neither is
  there (Safari cannot talk to USB or Bluetooth devices).
- To connect by USB, use a data cable in the socket on the watch's right-hand
  side (the left one only charges).
- Run setup again at any time to change the name, message, colour or
  shortcuts, or to remove it.

# Kit: everyday

For anyone: the kit to start from when a watch isn't for one subject. Needs no pack.

## What to make

| Part | File / source | Notes |
|---|---|---|
| Watch | [`docs/BUILD_GUIDE.md`](../../docs/BUILD_GUIDE.md) | Standard build |
| Lid | `enclosure/stl/lid.stl` (plain), or any pattern | |
| Base | Export with `base_text` / `base_text2` if you want a name on it | Optional |
| Desk stand | `enclosure/stl/desk_stand.stl` | Optional |

## The preset

- **Screens:** time, date, weather, timer (5 min), stopwatch, battery.
- **Apps:**
  - `FOCU`: a focus timer: 25 minutes on (`FOCU`), 5 off (`brEA`), repeating. It buzzes at each change.

Weather needs Wi-Fi and a place: set it in Watch Studio › Settings › Weather (*Use this computer's location* fills it in). See [`docs/USER_GUIDE.md`](../../docs/USER_GUIDE.md) › *Reading the weather*.

## Making it yours

More apps from Watch Studio › Apps › *Or start from*: exam countdown, birthday message, teams picker and others. The watch holds 8 apps.

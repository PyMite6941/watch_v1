# Kit: youth group

For someone who runs a youth group, club or camp. Needs no pack: it's the classroom tools, set up for games and gatherings.

## What to make

| Part | File / source | Notes |
|---|---|---|
| Watch | [`docs/BUILD_GUIDE.md`](../../docs/BUILD_GUIDE.md) | Standard build |
| Lid | `enclosure/stl/lid.stl` (plain), or any pattern | |
| Base | Export with `base_text` and `base_text2`: a name, a verse reference, the group's name | The personal touch for this kit. The text is mirrored so it reads correctly when the watch is turned over |
| Desk stand | `enclosure/stl/desk_stand.stl` | Game timer on a table where everyone can see it |

## The preset

- **Screens:** time, date, weather, timer (5 min), stopwatch, counter, dice. Weather needs Wi-Fi and a place (Watch Studio › Settings › Weather).
- **Apps:**
  - `GAnE`: game rounds: 5 minutes play, 1 minute rest, repeating. It buzzes at each change.
  - `GrUP`: random number 1–4. Each person presses SET to find out which team they're on. Change `max` for more teams.
  - `bE`: scrolls "bE StILL". Change the text in Watch Studio › Apps, up to 96 characters, with no K, M, V, W, X or Z.

## Ideas for using it

- **Head count.** The counter screen: a click per person getting on the bus, and again getting off.
- **Discussion timer.** The timer on the stand, so each small group sees how long is left.
- **Dice** with any number of sides (Watch Studio › Settings) for games.
- **Event countdown.** Add a countdown app for camp or a retreat date in Watch Studio.
- **Leaders' watches together.** Turn on watch-to-watch (mesh) on several watches with the same group name. Leaders can buzz each other, or send four characters such as `HErE`, `GO` or `5`, with no phones or router. Range is that of Wi-Fi, so expect one building, not a campsite. See [`docs/CONFIGURATION.md`](../../docs/CONFIGURATION.md) › *Watch-to-watch*.
